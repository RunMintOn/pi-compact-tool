# 01: 连续任务结束后结算一次统计

**What to build:** aggregate 在连续任务完全停止后显示一份完整统计。运行中的 steering、follow-up 和自动续跑合并统计；纯文字回答同样显示。重复 reload 或重新打开会话不重复显示或累计。

**Blocked by:** None (can start immediately).

**Status:** completed

- [x] 任务未完全停止时不显示统计；正常、中止、错误停止后显示一次。
- [x] 连续任务合并调用、轮数、耗时、token 和费用，停止后的新任务独立统计。
- [x] 无工具调用时省略工具相关项，缺失数据不编造。
- [x] 重复 reload 保持统计数量及数值；旧记录仅利用现有数据恢复，不迁移或猜测历史边界。
- [x] 会话和展示回归检查通过，其他风格及模型上下文不变。
