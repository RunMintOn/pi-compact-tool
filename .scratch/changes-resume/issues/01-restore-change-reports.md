# 01: 恢复会话中的修改报告

**What to build:** 恢复或重载会话后，用户仍能通过 `/changes` 打开当前对话分支最近生成的报告，历史任务统计行恢复各自的报告链接。切换分支和压缩上下文不会造成串报告或丢失关联。

**Blocked by:** None (can start immediately).

**Status:** done

- [x] 新生成的报告关联随会话保存，重启、恢复、重载后可用。
- [x] 历史统计行恢复对应任务的链接。
- [x] 当前分支没有报告时沿用现有提示；不扫描目录、不追溯旧会话。
- [x] 最近报告被删除或不可读时明确提示，不回退到更早报告，不启动浏览器。
- [x] 保持 off 模式行为；不更改报告内容、文件名或清理策略。
- [x] 自动化测试和中英文文档覆盖上述行为，不发布 npm。
