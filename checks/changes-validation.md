# 本轮修改查看验证

## 实现范围

- 只观察本扩展官方 Edit / Write 的写入操作，包括通过这些工具定义执行的嵌套调用。
- 起点快照在官方文件写入队列内保存，路径使用官方传入的绝对路径，随后按真实路径合并别名。
- `agent_settled` 结算整个任务，自动续跑不重置起点。只重新读取已登记的文件，不扫描仓库。
- 净 diff 由 `src/diff.ts` 直接对两份文件内容调用 jsdiff 的 `structuredPatch` 生成，不再先拼 patch 文本再解析回来。
- aggregate 统计第一行追加 OSC 8 `View changes`，优先保留后缀。第二行日期不变。`/changes` 等待任务结束，打开最近生成的 HTML。
- HTML 包含完整用户消息文本、时间、任务状态、文件与行数统计、文件侧边栏、Auto / Split / Unified、Wrap lines、自动明暗主题。
- 只保存独立 HTML，不保存额外原始快照或历史索引。链接关联不跨 reload／会话切换恢复。
- 1 MiB 单文件上限、16 MiB 起点快照预算。无法比较的文件明确显示 Unavailable。

## 阅读界面（markdown 优先）

真实使用中约 70% 的查看对象是 `.md`，因此界面按“读文档”而不是“看代码差异”设计。

- 侧边栏按类型分组，Markdown 在上，其余归入 Other，两组之间在正文中也有对应分隔。状态降级为行内标记，只有新增／删除／不可用带 `A`／`D`／`?`，修改是默认态不标记。
- 行内做词级 diff，只有真正变动的词被着色；markdown 的 `##`、`|`、`-` 等源标记保持可见，因为标记本身经常就是改动内容。
- 连续未改动的上下文可折叠，折叠只是切换 `hidden`，行仍在 DOM 中。每个折叠有独立 id，点开一处不影响同 hunk 的其他折叠。`src/diff.ts` 的上下文窗口取 10 行：jsdiff 把每侧上下文截断到该值，窗口太小时 hunk 内根本留不出足够长的未改动区间，折叠几乎不会触发。
- 改动块级导航：`↑`／`↓` 按钮与 `j`／`k`（`n`／`p` 同义），位置读数形如 `3 / 17`，当前块用强调色左边框标记。导航为瞬时跳转，不做平滑滚动——键盘高频操作下动画会被误读为卡顿，也会和滚动观察器互相干扰。

## 自动测试

```bash

```

类型检查通过；99 项测试通过，0 失败。

`tests/diff.test.ts`（5 项）不看实现细节，只验证不变量：每一行报告的内容必须真的位于它声称的那个行号上，插入行不得带旧行号、删除行不得带新行号、编号必须连续、`\r` 与 `\ No newline at end of file` 不得泄漏进正文。用例直接取仓库里的真实源文件做增删改，另加无结尾换行、CRLF、空文件、内容本身像 patch 头部、多个相隔较远的 hunk 等边界。这类断言在任何正确的 diff 实现下都成立，因此换实现时仍然有效。另有一项专门守住折叠前提：相隔 20 行的两处改动必须落在同一 hunk，并留下长于 6 行的未改动区间，否则页面永远折不起来。

## 浏览器检查

```bash
npm run test:changes-ui
```

脚本通过真正的 Edit / Write 生成四文件样例（含一个新增的 `NOTES.md`、一个含 HTML 注入载荷的新文件、一处纯缩进改动），使用 ego-browser 打开本地 `file://` 页面。无需模型调用。16 组检查通过：

1. 初始 1440 px 单栏，文件数与增删行数正确，Markdown 组在 Other 之前，无页面横向溢出，注入脚本未执行。
2. 词级 diff 生效：改动段落有增删两侧的行内标记，同时源文本保持原样。
2a. 折叠可独立展开：同 hunk 内多个折叠各有独立 id，点开一处只显示它自己的行，其余保持收起。
2b. 纯缩进改动两侧都渲染并被标记：`diffWords()` 会忽略空白，只有 whitespace-aware 的词级 diff 才能标出只改缩进的行。
3. 用户消息可展开，完整文字保留，长消息区域有滚动，嵌入脚本没有执行。
4. Wrap lines 切换为 `pre-wrap`。
5. 关闭折行后长行在块内滚动，页面不产生横向溢出。
6. 改动块导航显示 `n / m` 位置读数，初始高亮第一块。
7. 点击 `↓` 前进到下一块。
8. 再次前进到第三块。
9. `j` 前进。
10. `k` 后退。
11. 切换双栏后保留当前选中的文件；双栏同一 context 行渲染出两侧，并画出中间分隔线。
12. 模拟系统暗色偏好，页面配色改变且不是白底。
13. 600 px 窄窗口自动单栏、隐藏侧边栏且无整页横向溢出，位置读数换到第二行。
14. 窄窗口下禁用双栏；扩大回宽窗口后恢复双栏。

本次结果：`{ passed: 16 }`，产物目录由脚本打印。

上述第 2a、2b 两项做过反向验证：临时把折叠 id 改回共用 hunkId、把词级 diff 改回 `diffWords()`，对应断言分别以「each fold needs its own id」和「an indentation-only change must mark the whitespace on both sides」失败，确认它们不是空断言。

## 依赖

runtime 依赖从 `diff2html` 换成 `diff`。原先的流程是“生成 patch 文本 → 用 diff2html 解析回结构”，中间产物随即丢弃；现在直接产出结构，因此 diff2html 及其未执行的模板引擎 `@profoundlogic/hogan`（连同 `nopt`、`abbrev`）一并移除，共少 8 个包。`diff` 原本就在依赖树中（diff2html 与 Pi 宿主包都依赖它），现升为直接依赖。

同时去掉了 `diff2html/lib/types.js` 的深层导入——该路径并不在包的 `exports` 中，属于随时可能失效的用法。`src/changes.ts` 现在不再依赖 Pi 宿主包，只有 `index.ts` 仍需宿主包。

- `npm pack --dry-run --json` 确认 `src/changes.ts`、`src/diff.ts`、页面模板、浏览器 JS 和 CSS 都包含在包中（19 个文件，60 KB）。
- Pi 宿主包与 `typebox` 继续使用已有安装的软链接。注意：`npm install` 会清掉这些软链接，装完需要重新建立，否则类型检查报找不到模块。
- 使用 `npm install --ignore-scripts --legacy-peer-deps`，不将 Pi 的第二份副本写入锁文件。锁文件改动只有删除，没有新增条目。
- `npm audit --omit=dev --legacy-peer-deps`：0 vulnerabilities。
- 自包含页面保留内嵌库的许可证／版权说明。
- 用户已有未提交修改保持不动。

## 已知限制

- 词级配对按位置进行。“删除 3 行、插入 1 行”时多出来的删除行只能整行标记，无法给出更细的词级对照。
- 已有的历史 HTML 是自包含静态文件，仍使用当时内联的旧样式，不会随本次改版变化。
